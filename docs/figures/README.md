# Figures

`fig1_architecture.png/.svg` - architecture figure of the paper (Figure 1).

`article/` - Figures 2-5 of the paper, one file per panel (600 dpi PNG; plots also as vector PDF). Panel letters are
part of the file names, not drawn on the images. All files are generated by the scripts in `../../src/` from the
stored predictions, logs and epoch-20 models.

| Files | Content | Script |
|---|---|---|
| `Fig2a-c_learning_curve_*` | Learning curves (mean and SD over 15 runs): Vim-S, ResNet-Mamba-MLP, ResNet-Mamba-KAN | `plot_learning_curves.py` |
| `Fig3a-d_confusion_*` | Pooled confusion matrices: Vim-S, hybrid MLP, hybrid KAN, ensemble E1 | `plot_confusion_matrices.py` |
| `Fig4a-d_ig_main_*` | Integrated-Gradients examples: original image, Vim-S, hybrid MLP, hybrid KAN | `xai_integrated_gradients.py` |
| `Fig5a-d_*` | IG overlap (IoU), insertion gain, deletion gain, model-randomisation check | `xai_integrated_gradients.py` |

The supplementary figures (per-run validation curves, Figure S1; IG examples per class and for misclassified images,
Figures S2 and S3) are part of the journal's supplementary material and are not duplicated here.
